# Sales Operations Dashboard

## Overview

This is a personal portfolio project demonstrating practical skills in sales operations, CRM management, lead tracking, customer support, and sales reporting.

The project uses a sample dataset to demonstrate how sales information can be organized, analyzed, and presented to support better business decisions.

## Project Goals

- Track and organize sales leads
- Monitor lead stages and pipeline activity
- Calculate conversion rates
- Identify sales performance trends
- Create clear and useful sales reports
- Demonstrate structured data management

## Skills Demonstrated

- Sales Operations
- CRM Management
- Lead Qualification
- Pipeline Management
- Customer Support
- Data Entry & Data Management
- Sales Reporting
- Basic Data Analysis
- Process Documentation
